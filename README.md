Vinylity is a rythm game that tests your patience. The game never ends, meaning you can keep rocking out these PERFECT scores for how much time you want to. The songs keep LOOPing, but the game gets harder and harder. Post a screenshot with how high you could get the Score!!!

Sadly we couldnt get a Web build running that makes the game run somewhat accurate, thats why you will have to download the game.. we are sorry ): 

(the Linux version has not been tested, hope it works)
Controls:

D F J K = hit notes

To pause the Game press SPACE or ESCAPE!
Information:

"Vinylity" was made in about 3.5 days for the GMTK Game Jam 2025 with the theme "LOOP" by gabl, sir_lordmike and ilem.
